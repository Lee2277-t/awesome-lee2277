审计实习工具箱

会计师事务所实习里最费时间的五件事，各有一个小工具。

不装软件 不联网 数据不出本机 双击 index.html 就能用

底稿填充助手

序时账按客户汇总，填进底稿明细表的空白行，表里自带的公式一行都不动。
填之前先告诉你「往第几行到第几行填」，你改了行号就严格照你给的填。

在线打开 下载 ZIP
填完生成 Excel 宏，在 Excel 里跑，格式和公式全部保真。

勾稽助手

明细表 → 科目余额表 → 试算表，三级勾稽逐项对账。
漏科目、重复计、单边项目，一次列全，给出行号。

在线打开 下载 ZIP
认错列可以切「高级」自己指定，工具不猜。

抽凭助手

认表、设定总体与抽样、生成抽凭表、回录评估，一条流水线。
大额全查 + 其余均匀抽样，金额越大越容易进样本。

在线打开 下载 ZIP
没有数据也能点「用示例数据试一下」看效果。

截止测试助手

按资产负债表日切分单据流水，生成截止测试底稿。
期前／期后两边分开，跨期单据直接标出来。

在线打开 下载 ZIP

函证助手

从往来余额表生成函证控制表和询证函。
选样、编号、发函记录、回函登记一张表跟下来。

在线打开 下载 ZIP

在线打开和下载 ZIP是同一份代码，都是纯前端页面，你的表格只在浏览器里读，不会上传到任何地方。 介意联网的话就下载 ZIP，断网也能用。
